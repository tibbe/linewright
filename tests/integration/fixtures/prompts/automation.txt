## output

End your session with a final message that is a single JSON object and nothing else:

```
{
  "summary": "<Markdown: what you did and found>",
  "issues": [ISSUE]
}
```

where `ISSUE` is `{ "title": "<issue title>", "body": "<the issue's Markdown body>", "label": "ready-for-agent" | "ready-for-human" }`, and `issues` lists the issues to file (often none), each as _Issues_ says.

To show a screenshot or a video in the Markdown your result posts, save the file in your attachments directory, `/work/sessions/issue-7/20261001T120000Z-implement/attachments`, and refer to it by its absolute path there: as the destination of a Markdown image (`![what it shows](/path/to/file.png)`) or link, or as an HTML `img`'s `src`. Linewright uploads each file you refer to and puts its URL in place of the path. A video (`.mp4`, `.mov` or `.webm`) embedded alone in its paragraph plays inline; anywhere else it becomes a link to it.
