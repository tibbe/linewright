# Shell on the web

- **Navigation** is a sidebar. Where the page does not fit
  beside it, it is a rail of the links' icons and labels. Where the page does
  not fit beside the rail, it is a menu behind a button.
- **In the rail**, the repository's name is in a daisyUI `tooltip`.
- **A hold or a problem** is a daisyUI alert across the top of the page.
- **The breadcrumbs** are daisyUI `breadcrumbs`.
