# Web architecture

Linewright's web UI is rendered on the server.

## Serving

`serve` serves the web UI itself, on a port of its own.

## Rendering

Pages are askama templates, with htmx.

- **Live updates.** A live update is a server-sent event carrying an HTML
  fragment, one event stream per page.

## Styling

The UI is styled with daisyUI, on Tailwind.

- **The stylesheet** is generated by Tailwind's standalone CLI, and
  committed.

## Assets

The assets are in the binary (`rust-embed`).
