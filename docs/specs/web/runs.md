# Runs on the web

## Runs

- **Item and Since** are `input`s, and **Stage** is a `select`.
- **"By hand"** is a daisyUI `badge`, `badge-sm`, with no colour or style
  class.

## Run

- **The transcripts** are each a [transcript](components.md#transcript).
- **The verbose switch** is a daisyUI `toggle`.
- **"Jump to the latest entry"** is a button with `shadow-md`, fixed at the
  bottom right of the screen, `bottom-6` and `right-6`.
