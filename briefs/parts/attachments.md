To show a screenshot or a video in the Markdown your result posts, save the file in your attachments directory, `{{directory}}`, and refer to it by its file URL: `file://` followed by the file's absolute path, percent-encoded where the path holds a character a URL cannot, such as a space (`%20`). Use the file URL as the destination of a Markdown image (`![what it shows](file:///path/to/my%20file.png)`) or link (`[what it is](file:///path/to/file.mp4)`), or as an HTML `img`'s `src` (`<img src="file:///path/to/my%20file.png" width="300">`). Linewright uploads each file you refer to and puts its URL in place of the file URL. A video ({{videos}}) embedded alone in its paragraph plays inline; anywhere else it becomes a link to it.

Only images and videos can be attached: {{kinds}}. Refer to no other file this way. Put anything else, such as text output or a log, in the Markdown itself, in a fenced code block or a `<details>` block when it is long.
