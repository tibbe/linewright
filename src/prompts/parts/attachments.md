To show a screenshot or a video in the Markdown your result posts, save the file in your attachments directory, `{{directory}}`, and refer to it by its absolute path there: as the destination of a Markdown image (`![what it shows](</path/to/file.png>)`) or link (`[what it is](</path/to/file.mp4>)`), or as an HTML `img`'s `src`. Keep the angle brackets around the path, since it may contain spaces. Linewright uploads each file you refer to and puts its URL in place of the path. A video ({{videos}}) embedded alone in its paragraph plays inline; anywhere else it becomes a link to it.

Only images and videos can be attached: {{kinds}}. Refer to no other file this way. Put anything else, such as text output or a log, in the Markdown itself, in a fenced code block or a `<details>` block when it is long.
